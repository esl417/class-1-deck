3.5 / What is an MCP server?
The thing you installed for the prereqs

How Claude actually reaches your tools.

To set up, you connected Claude to Google Analytics and Supabase. Each connection is an MCP server — think of it as a standard plug that lets Claude talk directly to an outside service.

On its own, Claude can only talk. An MCP server gives it hands — a safe, defined way to actually do things in another tool.
Without MCP

Claude can tell you what SQL to run or where to click — but you'd have to go do it yourself in another app.

With MCP

Claude does it directly — reads your real analytics, creates tables in your real database — because the plug is connected.

Same idea as USB: one standard shape, and anything can plug in. New tool you want Claude to use? There's probably an MCP server for it.

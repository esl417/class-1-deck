# Course Intro — Outline

The video that sits at the top of the free-course playlist. Job: a cold viewer
understands what the six classes build, why it is worth their time, and what to
do next. Target 7–9 minutes. Sources: CLASSES-OUTLINE.md, PRODUCT.md,
jerry-droplet/course-positioning-strategy.md, jerry-droplet/YOUTUBE-STRATEGY.md.

## 1. Open — the thesis (0:00–0:45)

- One line, first: one person can now run a business with the leverage of a
  ten-person team, for almost nothing. Stop renting your marketing and
  operations. Own them.
- Who this is for, plainly: you already run a service business (consultant,
  coach, therapist, solo practitioner, small agency) and you are running it by
  hand.
- The promise: six classes. You leave with a website you own, a dashboard that
  reads it, a site that gets found by Google and by AI, routine work that runs
  without you, software that makes judgment calls, and a plan to sell. Every
  class ends with something live on a real URL.

## 2. Why me (0:45–1:30)

- Former CPA, not an engineer. Built the entire stack myself: StratEngine,
  Venice Threads, SCUBAzen. No other human has touched the code.
- The proof is the point: the tools taught here are the tools those businesses
  run on. Class 6 puts you inside StratEngine, a product built exactly this way.
- Line to echo: this is an architecture problem, not a coding problem.
- Screen rule: no revenue, customers, metrics, or billing on screen. Show the
  products, not the numbers.

## 3. The one idea under everything (1:30–2:15)

- You will never type code. You type English. You delegate to Claude Code the
  way you would delegate to a person, and you review the work.
- The foil, briefly: the no-code template stacks most viewers have already
  tried. Hidden monthly tool bills, templates that break when an API changes,
  courses that push you to start an agency instead of running your own
  business. Here you own the code and the running cost is near zero.
- Framing line: Anthropic teaches you the tool for free. This teaches you the
  business.

## 4. The map (2:15–3:00)

- One slide, six classes, one arc: build → measure → get found → automate →
  give it judgment → sell.
- The thread: the site you build in Class 1 is what you instrument in Class 2,
  get found in Class 3, and sell in Class 6. Nothing is a throwaway exercise.
- Two habits carry the whole series: plan mode (Claude plans before it builds)
  and reference docs (a Wikipedia for your project).

## 5. Class by class (3:00–7:30, about 45s each)

Each beat: what you walk out with, the one plain-English idea, the habit it adds.

**Class 1 — How to Build a Website**
- Walk out with: a live site on a real URL. No coding.
- Idea: the four tools and what each does. Claude Code builds, VS Code is the
  file manager, GitHub is Google Drive for code, Vercel is free hosting that
  publishes on push.
- Habit: permanent instructions (CLAUDE.md) and specialist Claudes that review
  code and security automatically. Local is practice, push is publish.

**Class 2 — How to Build a Dashboard**
- Walk out with: a password-protected dashboard that fits how *you* decide.
- Idea: a database is just labeled spreadsheets. Google Analytics is the
  recorder, Supabase is the storage. Build the data pipeline first, then the
  screen. A decision tool, not a report.
- Habit: plan mode, reference docs, and Claude operating tools through MCP.

**Class 3 — SEO + GEO**
- Walk out with: your site found by Google and cited by ChatGPT, Perplexity,
  and AI Overviews.
- Idea: getting found is now two jobs. The dual-surface site: one source of
  truth, rendered once for people and once for AI crawlers, routed by a free
  Cloudflare Worker. Say "single source of truth, dual rendering" out loud so
  the cloaking objection dies on contact.
- Optional stat (verify before recording): consumers using AI for local
  business recommendations went from 6% to 45% in a year, and AI recommends
  about 1% of local businesses (BrightLocal 2026).

**Class 4 — Automations**
- Walk out with: a morning briefing that runs on its own and tells you what
  actually needs you today.
- Idea: an automation is a chore you would do by hand. Map the steps, hand the
  map to Claude. Fixed rules for everything; call Claude only where a rule
  cannot decide. It tells you when it breaks, because silence never means fine.
- Habit: API keys are passwords. They live in a file, never in the chat.

**Class 5 — Agents** (not yet built; keep to the promise)
- Walk out with: software that chooses, not just follows rules.
- Idea: an agent is instructions, tools, and a loop. The readers and the
  CLAUDE.md from Class 4 become its tools and personality, already debugged.
- Habit: guardrails and a human in the loop.

**Class 6 — Go-To-Market** (not yet built; keep to the promise)
- Walk out with: an implementation plan to sell what you now own.
- Idea: positioning, audience, offer. You run your own business through
  StratEngine, which runs the full analysis, about an hour end to end. Measure
  it with the dashboard from Class 2.
- Frame StratEngine as the recursive proof, not a pitch.

## 6. What it takes, honestly (7:30–8:00)

- Time: each class is one sitting. The Class 1 setup is about an hour, done
  once, before class.
- Money: free tiers for the tools plus a Claude subscription. Say the real
  number.
- Not for: people building a software product, people who want to sell AI
  services to clients, and people with only a loose idea. For the last group,
  point to consulting on ericgrows.com without apology.

## 7. Call to action (8:00–8:30)

- Do the Class 1 prerequisite setup first (link on screen and in the
  description), then start Class 1. The playlist is in teaching order.
- Site: ericgrows.com.
- Close declarative, on the thesis: your business can run without you doing
  every job in it. Start with the setup video.

## Guardrails for the script

- Verb razor: you are the subject, AI is the instrument. Never "AI builds it
  for you."
- "Former CPA." Never present tense.
- No last name anywhere.
- No private data on screen.
- No foil-lane vocabulary (no-code, vibe coding, AI automation agency).
- No question as a sign-off.
- StratEngine: "runs the full analysis," "about an hour end to end." Never
  "tells you where it breaks" or "comes back in about an hour."
- Warm, plain-spoken, reassuring. Name the scary thing, then demystify it.
